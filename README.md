# ميزانك 4.1

[تحميل نسخة Windows كاملة](MIZANAK_v4_1.zip)

فك الضغط ثم شغّل `START_WINDOWS.bat` داخل المجلد. أوقف النسخة السابقة أولًا إن كانت تعمل.

تتضمن هذه النسخة إصلاح شريط التمرير بجانب اختيار اللغة، وأزرار مساعدة بأيقونة الاستفهام والسهم فقط، والقياسات المحسوبة أسفل المدخلات، وأوصافًا مختصرة للأمراض مع تنبيه طبي، واستبدال «عتبة النموذج» بعبارة «حد التنبيه».

احتُفظ بصورة قياس الخصر والشعار الأصليين. معاينات الشعار الجديدة غير مطبقة في البرنامج.

اجتازت النسخة 43 اختبارًا على Windows وLinux. نتائج النماذج تقديرات بحثية ولا تغني عن التقييم الطبي.
