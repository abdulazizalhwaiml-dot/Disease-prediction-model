## التشغيل على Windows

1. فك الضغط وافتح مجلد `MIZAN_v2`.
2. انقر `START_WINDOWS.bat` مرتين. يلزم Python 3.12 بنسخة 64-bit.
3. بعد اكتمال تجهيز الحزم افتح http://localhost:8501 . أبقِ نافذة التشغيل مفتوحة.

الحزمة تشمل المصدر، والبيانات الأصلية، وثمانية نماذج مدرّبة، ونسختي CSV وExcel من بيانات التدريب، وصور الواجهة، والوثائق والاختبارات.

المصدر المحدّث متاح في [فرع التطبيق](https://github.com/abdulazizalhwaiml-dot/Disease-prediction-model/tree/feat/mizan-v2-eight-inputs). فرع التنزيل هذا مخصص للحزمة الكاملة.

المشروع بحثي تجريبي وغير معتمد للاستخدام الطبي. تعريف الكوليسترول: الإبلاغ الذاتي بالتشخيص أو non-HDL ≥190 mg/dL.
