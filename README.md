# ميزانك 4.1

[تحميل نسخة Windows كاملة](MIZANAK_v4_1.zip)

فك الضغط ثم شغّل `START_WINDOWS.bat` داخل المجلد. أوقف النسخة السابقة أولًا إن كانت تعمل.

تتضمن هذه النسخة إصلاح شريط التمرير بجانب اختيار اللغة، وأزرار مساعدة بأيقونة الاستفهام والسهم فقط، والقياسات المحسوبة أسفل المدخلات، وأوصافًا مختصرة للأمراض مع تنبيه طبي، واستبدال «عتبة النموذج» بعبارة «حد التنبيه».

اعتمد الشعار بشاشة مفرغة ومستطيلة منحنية الأطراف في الترويسة وأيقونة المتصفح. الرسم الترحيبي يجمع بطاقة قياسات وشريط قياس وقلبًا صغيرًا، واحتُفظ بصورة قياس الخصر السابقة.

اجتازت النسخة الأساسية 43 اختبارًا على Windows وLinux. واجتاز تحديث الرسوم اختبارات التطبيق الأربعة وفحص العرض الفعلي بالعربية والإنجليزية بثلاثة مقاسات للشاشة. نتائج النماذج تقديرات بحثية ولا تغني عن التقييم الطبي.
