# MIZAN v3 — ready project

Download **MIZAN_v3.zip**, extract it, open the project folder and double-click **START_WINDOWS.bat**.
Requires 64-bit Python3.12. The archive contains source,77 original NHANES files, the merged
21,117-row dataset, eight trained models, reports and Arabic/English instructions.

Research only, ages20–79; not medically validated. Includes simplified fixed wellness messages.

This branch stores the downloadable archive only. For Streamlit Cloud use branch
`deploy/streamlit-cloud`, entrypoint `streamlit_app.py`, Python3.12.
