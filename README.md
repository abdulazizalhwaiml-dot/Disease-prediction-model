# ميزانك | Mizanak v4

نزّل **MIZANAK_v4.zip**، ثم فك الضغط وافتح مجلد المشروع وانقر **START_WINDOWS.bat**.
يلزم Python3.12 بنسخة64-bit. النماذج المدربة والبيانات مرفقة، ولا يلزم إعادة التدريب إذا كانت متوافقة.

- واجهة عربية/إنجليزية بسيطة: المدخلات فوق والتقرير تحت، مع انتقال تلقائي بعد الإرسال.
- شعار قريب من المرجع: ميزان مربع بالتركوازي مع شاشة صغيرة وخط نبض ولمسات رمادية.
- توضيح لكل خانة، ورسومات للطول وقياس الخصر عند أعلى عظم الحوض الأيمن.
- إصلاح حفظ التقارير على Windows بترميز UTF-8 وتصدير XGBoost بصيغة قابلة للنقل.
- نجحت الاختبارات الـ43 على Windows وLinux؛ نماذج الأعمار20–79 والبيانات المدمجة مرفقة.

هذه نسخة تنزيل؛ فرع الاستضافة هو **deploy/streamlit-cloud** ونقطة البداية **streamlit_app.py**.
مشروع بحثي تجريبي للأعمار20–79، غير معتمد طبيًا. انخفاض التقدير لا يؤكد الخلو من المرض.

أغلق النسخة القديمة بـCtrl+C قبل تشغيل النسخة الجديدة على المنفذ نفسه.
